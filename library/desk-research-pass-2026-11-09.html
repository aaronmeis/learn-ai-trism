Run 2026-11-09. Searched vendor explainers and AWS mapping. Found capability checklists and cloud mappings, not a published design-review architecture that treats TRiSM as the sole auditable anchor. No positive example found; Claim A remains weak.

Run 2026-11-09. ISO insights: certification voluntary; ISO does not certify; independent CBs do. ANAB accredits CBs to ISO/IEC 42001 and references ISO/IEC 42006:2025. Claim B strengthened: yes, certifiable management-system route exists.

E2W — NIST AI RMF conformance route

Run 2026-11-09. NIST AI RMF 1.0 and AI 600-1 both state voluntary use. No NIST certification scheme found. Does not break Claim B's contrast; softens "auditable" for NIST itself. Prefer ISO for conformance; NIST for risk vocabulary.

E3A — OWASP LLM01 mitigation mix

Run 2026-11-09. Seven mitigations on LLM01:2025:

# Mitigation Bucket
1 Constrain model behavior (system prompt) process / prompt design
2 Define and validate expected output formats filtering / inspection
3 Input and output filtering filtering / inspection
4 Privilege control and least privilege privilege / architecture
5 Human approval for high-risk actions process
6 Segregate and identify external content architecture / process
7 Adversarial testing; treat model as untrusted user process

Count: about 2 clear filtering items; about 5 privilege/architecture/process. Supports Claim B's weight on architecture; does not erase Claim A's need for runtime inspection.
