Pack: Hub · Views: Conceptual · Logical · Physical · Integration · Detailed design · Ledger: source-ledger

Business Explanation

Review rooms speak different architecture dialects. TOGAF ADM phases name the work cycle. DoDAF viewpoints name the product set still common in U.S. defense briefs. UAF 1.3 is the OMG grid that donor frameworks (including DoDAF) feed into, and OUSD(R&E) guidance already builds mission architecture on UAF. This crosswalk keeps one AI-TRISM placement map and shows the same elements in all three languages.

Grounding rules

  1. AI-TRISM sources do not prescribe TOGAF, DoDAF, or UAF. Placement is the architect's overlay on pack elements (capabilities, components, zones, standards). Mark that honesty in the room.
  2. UAF cells use UAF 1.3 Figure 7-1 labels (domain-aspect, e.g. Op-Sr). Grid literacy: vault brief 00_Resources/Machine_Library/architecture/ARCH-20261027-0849-uaf-dodaf/uaf-dodaf-brief.md and ledger [S17] [S18].
  3. DoDAF stays in the table. DoD direction points toward UAF; no signed CIO replacement of DoDAF 2.02 was found in the UAF brief. Teach both until policy catches up [S18].
  4. Silence stays silence. SKUs, regions, and gov-cloud rows that are UNVERIFIED in the views stay UNVERIFIED here.

Companion NotebookLM export (TOGAF/DoDAF only, pre-UAF): NBLM TOGAF/DoDAF crosswalk. Prefer this vault note when UAF is required.
